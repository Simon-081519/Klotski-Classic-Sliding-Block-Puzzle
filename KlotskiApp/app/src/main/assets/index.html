100 classic-board levels. Each level starts pre-scrambled and gets tougher as you climb — solve one to unlock the next.

How to Play

Move blocks by clicking/tapping them, then use the arrow keys — or simply drag/swipe them. Blocks can only slide into empty space.

Goal

Slide the large red block down to the exit at the bottom of the board.

Controls

🖱 Mouse / touch: drag a block
⌨ Keyboard: arrow keys move the selected block
↺ Reset: restart the current puzzle
🎲 Randomize: generate a new solvable layout

Tips
  • Plan several moves ahead before sliding a block.
  • Create empty space strategically near the exit.
  • Avoid unnecessary back-and-forth moves.
  • Try to solve each puzzle in as few moves as possible.

About the Game

Klotski (also known as Hua Rong Dao) is a classic sliding-block puzzle. Rearrange the blocks so the large target block can slide out through the exit, using as few moves as possible.
